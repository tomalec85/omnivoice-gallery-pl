# Głosy instruktorek BHP (VoiceStudio)

Zestaw zaprojektowanych głosów kobiecych do **prowadzenia szkoleń BHP** w VoiceStudio / OmniVoice.

Barwa: dorosła, wyraźna, rzeczowa. Bez szeptu i głosu nastolatki.

## Głosy

| ID | Rola |
|---|---|
| `bhp_instruktorka` | instruktorka szkolenia |
| `bhp_lektorka` | lektorka e-learningu |
| `bhp_trenerka` | spokojna trenerka (niższa) |
| `bhp_specjalistka` | specjalistka BHP |
| `bhp_prowadzaca` | prowadząca onboarding (przystępna) |
| `bhp_inspektorka` | inspektorka — stanowcza |

Źródło w aplikacji: `gallery_sources.json` → `tomalec85/omnivoice-gallery-pl`.
